# 🎬 Brian's Theater Web

Welcome to the official web portal for **Brian's Theater**! This site connects our cinema community with live showing schedules, real-time movie countdowns, an interactive trailer lounge, our 398+ movie vault, and community movie requests.

---

## 🌟 Key Features

- **🍿 Screening Room**: Live auditorium marquee, active film status, real-time runtime ticker, and 1-click theater entrance.
- **⏳ Schedule & Countdown**: Precision countdown timer ticking down to the exact second of the next movie premiere.
- **🎥 Interactive Trailer Lounge**: Full-width 16:9 widescreen YouTube trailer player with custom trailer lookup.
- **🔍 398+ Movie Vault**: Instant client-side fuzzy search across our entire historical library and community requests.
- **📝 Request Kiosk**: Direct submission form for movie requests synced with Brian's Theater Google Sheets.
- **📊 Showing Stats Billboard**: Live counter of movies screened, TV series episodes, days open, and live clock.
- **🔒 Google Authentication**: Secure admin access restricted exclusively to authorized Google accounts.

## 🛡️ Security & Privacy
- **Zero Hardcoded Secrets**: This static site contains no API secrets, database passwords, or private keys.
- **Client-Safe Endpoints**: Interacts strictly with public read-only counters and sandboxed Google Apps Script forms.
- **Zero PIN Codes**: Insecure PIN bypasses have been completely removed in favor of authenticated Google OAuth.
